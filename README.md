# Aplikasi Pengelolaan Data Peserta Sertifikasi

Aplikasi web untuk mengelola data peserta dan skema sertifikasi.

## Teknologi

* Laravel 13
* PHP 8.3
* MySQL
* HTML & CSS

## Fitur

* Login Admin
* Dashboard
* Data Peserta
* Tambah Peserta
* Edit Peserta
* Detail Peserta
* Hapus Peserta
* Pencarian Peserta
* Data Skema Sertifikasi
* Tambah Skema
* Edit Skema
* Detail Skema
* Hapus Skema
* Validasi Data
